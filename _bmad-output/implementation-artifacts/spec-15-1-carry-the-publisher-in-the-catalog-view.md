<intent-contract>

## Intent

**Problem:** The catalog view's `ShelfBook` doesn't carry the Book's publisher, so Story 15.2's Publisher ▾ filter has nothing to filter on.

**Approach:** Add a required `publisher: str` to `ShelfBook`, filled from the stored (already trimmed) `Book.publisher`; regenerate the client types. Catalog, Home and `list_catalog` all serve `ShelfBook`, so they gain the field with no other change.

## Boundaries & Constraints

**Always:** pass the stored value as is (no case merging or normalizing: "manning" stays "manning"; Story 15.2 merges on the client). Regenerate `schema.d.ts` only with `npm --prefix frontend run api:gen`, never by hand or formatter. Any `ShelfBook` fixture `tsc -b` names gets `publisher` through its shared helper.

**Never:** no domain, store, backup format, intent, agent-tool description/arguments, page or component change; nothing visible changes. No README edit. No tree-wide git state changes (AGENTS.md "Story pipeline", Epic 8 retro item 64).

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|--------------|---------------------------|----------------|
| Stored publishers | Books with "Manning", "O'Reilly Media", "manning" | each `ShelfBook.publisher` equals the stored string, apostrophe and case intact | No error expected |
| Edited publisher | `edit-book` with `"  Ace Books  "` | next fetch carries `Ace Books` | No error expected |
| Agent read | `list_catalog` | Books carry `publisher`; description and `inputSchema` unchanged | No error expected |

</intent-contract>
